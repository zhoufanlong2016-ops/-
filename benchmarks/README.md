# 工程翻译基准数据集

`engineering_translation_100.jsonl` 是阶段0B-1的离线中英工程翻译基准，包含50条中文→英文和50条英文→中文样本，覆盖道路桥涵、污水管网、MTBM顶管、测量、混凝土钢筋、土方地基、施工质量安全、合同报审/RFI、电气与SCADA/通风除臭及通用工程函件。

每条记录包含候选参考译文、术语映射和必须逐字保持的数字、单位、桩号、标准号、编号或占位符。`review_status`统一为`candidate`，表示参考译文尚未完成独立人工审定，不能当作已批准金标准。

人工审核后，应逐条检查源文、参考译文、术语映射和保护字面量；确认无误后，才可将该条的`review_status`改为`approved`。修改必须保留稳定唯一的`id`，并重新运行`tools/validate_benchmark.py`。

校验工具只能判断JSONL结构、方向、ID、字段、术语和保护字面量等确定性项目。后续评测可以比较模型输出与参考译文的确定性差异，但自动评分不能代替工程术语、遗漏、增译、数字语义、合同效力和整体翻译质量的人工判断。
